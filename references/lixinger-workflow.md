# 理杏仁网页导出与 PDF 下载

先核准公司名称、代码和三表导航。通过可用浏览器工具操作已登录页面，登录或验证码需要用户介入时，继续做不依赖登录的本地工作。`scripts/lixinger_browser.js` 是可复制到浏览器 JavaScript 工具的函数，不是一个可在终端直接控制浏览器的命令。

## 表格导出

1. 设定分析日期范围。年度合并、年度母公司各取资产负债表、利润表、现金流量表；再取最新中期及其可比期。每切一次报表/主体，都重新看实际选项、URL 和表头，页面会记住不同设置，母公司页面可能自动回到年度。
2. 展开“导出CSV”。优先选择 **标准、壹、时间横排—升序**；利润/现金流确认累计口径。标准格式减少平台计算指标混入，并以元而非页面显示的亿元导出。实际精度仍由导出的原值决定，不能认为网页数据已精确到分。
3. 在浏览器工具会话定义包内 `exportLixingerCurrent` 后调用，例如：

```javascript
const exportRecord = await exportLixingerCurrent(tab, {
  company:'贵州茅台', statement:'ps', scope:'consolidated',
  granularity:'q', start_date:'2020-01-01', end_date:'2026-11-05'
});
nodeRepl.write(exportRecord);
```

`tab` 必须是工具文档提供、当前有效的页面句柄。函数检查公司、URL、页面周期和导出设置，使用实际下载事件取得本地文件，并返回待归档的来源记录。传入其他公司及本次实际日期。不要用旧页面句柄或硬编码元素序号。

浏览器工具可用能力不同，函数不能直接使用时，按同样的已观察控件完成操作。单选控件可能点击未生效，读状态再决定；已从页面确认的链接及筛选参数可直接导航，导航后核准实际页面。函数发现口径不符会停止，不把母公司年度误标成季度。

4. 检查**下载文件本身**的日期行、财报类型、范围、单位和行列数。2026-11-05 实测茅台标准季度导出包含 2020Q1—2026Q3 共 27 期，虽然页面只显示 9 季；未来导出仍须核查，不能将此案例当成网站永久承诺。母公司界面本次回到年度，中期母公司从半年报原件取得。缺少季报母公司数据不补零。
5. 原件保持 `.csv`（可用 Excel 打开），网页实际提供 XLSX 才记录为 XLSX。将返回的记录作为 `source_archive.py ingest --settings` 内容并归档。以原格式复用为主；另做工作簿时保留源表、公式及来源，不把 CSV 改后缀冒充 Excel 工作簿。

两种实际 CSV 版式：旧网页版前 3 列为科目/代码/主体或名称，后续为各期间；标准格式只有第 1 列科目，其余为各期间，代码/名称/日期/货币各占元数据行。用包内导入器探测日期行，不能固定截掉前 3 列。

## PDF 原件

表头报告期旁的 PDF 图标通常是空文字链接，`title`/无障碍标签包含报告名和公告日期。先读链接的实际属性，再用浏览器的链接下载能力，例如：

```javascript
const links = await tab.playwright.evaluate(() =>
  Array.from(document.querySelectorAll('a[title]'))
    .filter(a => /年度报告|半年度报告|季度报告/.test(a.title))
    .map(a => ({title:a.title, url:a.href}))
);
nodeRepl.write(links);
// 从已观察到的真实标题选择一项；同一PDF在表头/表尾可能重复。
const path = await tab.playwright.locator('a[title="已观察到的完整标题"]').first()
  .downloadMedia({timeoutMs:25000});
```

每份检查 PDF magic、`pdfinfo`、封面公司/期间及是否完整全文。某些链接打开阅读页、验证页或返回 HTML，不等于已下载 PDF。保留失败链接和原因，使用同一披露的巨潮、交易所或公司官方公开原件补齐，`source_archive.py --url --verified-public` 可下载已核准直链。不解网页验证、不复制登录会话。

年报全文每年保留；最新半年报提供详细更新附注，最新季报及上年同期提供可比期间。重大关联交易、政策变化、财务公司风险评估等独立公告按问题补充。后续按 [原件与 PDF 工作流](source-workflow.md) 逐期阅读并留底。

## 脚本分工

| 可重复执行的操作 | 负责资源 | 仍需 AI 确认 |
| --- | --- | --- |
| 网页下载事件、设置校验、来源记录 | `lixinger_browser.js` | 当前页面、公司与可用导出范围 |
| 公开原件下载、去重留版本、哈希及 PDF 验证 | `source_archive.py ingest` | 官方来源、全文/摘要、期间 |
| 逐页提取、主题索引、阅读覆盖记录检查 | `source_archive.py extract/coverage` | 完整阅读与重要事项判断 |
| CSV 归一化、显式映射、计算及 PDF 输入核对 | `financial_pipeline.py` | 层级/符号/口径/重述与采用依据 |
| 带单位及来源的趋势图 | `plot_financials.py` | 指标选择、期间可比与解释 |

这些机械环节可高度自动化；完整 PDF 阅读、因果判断及资本配置评价不按“自动化百分比”虚称完成。
