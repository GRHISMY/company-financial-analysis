# 客户价值与盈利机制

完整研究先建立业务解释，再用三表验证；只研究一个局部问题时，补足与该判断有关的链条。沿着“客户问题 → 可兑现的交付 → 付款与分利 → 全成本利润 → 现金及再投入”调查，依据新证据修正解释。

创造价值解释客户为何愿意买，价值获取解释企业为何能留下利润。付费意愿、实际受益、承诺履行和道德评价分别取证；利润也可能受到选择受限、信息不对称、政策或暂时供需影响。高利润不自动证明履责，客户受益也不保证企业获利。

## 把责任落到具体的人和结果

按重要业务辨认使用者、购买决策者、付款者、最终受益者及渠道伙伴；角色可重合，也可分离。追踪谁承担库存、资金、维护、误用或其他外部成本。

写清企业实际承诺的性能、交付、服务和合作条件，以及哪些结果受客户经营与市场需求影响。区分企业宣传、合同/产品承诺与实际兑现。体验、效率、风险下降、信息成本及文化表达都可成为价值，但购买动机和改善效果需要证据。

## AI需要回答的问题

- **为什么付钱？** 客户有什么具体问题，替代方案是什么，选择和付款是否出于真实需求？把客户动机作为待验证解释，避免从广告语推导实际效果。
- **为什么选它？** 技术、可靠性、品牌、网络、渠道、切换成本或交付能力如何影响选择？区分质量、价格和便利性，说明竞争者为何难以提供同等方案。
- **利润留在哪里？** 沿制造、渠道、服务与最终购买追踪价格和分利，纳入研发、获客、售后、税费、营运资金及维持投入；分清毛利、净利、现金和资本回报。公司利润增加时，检验新增价值与价值转移两种解释。
- **能否持续？** 消耗、换新、复购、扩产或客户新增需求怎样形成下一笔订单？检验客户实际回报、渠道周转和履约质量，并给出会推翻解释的条件。耐用性可提高客户价值，同时延长换机周期。

## 用财务证据验证，而非反向编故事

| 盈利解释 | 相互核对的证据 | 应调查的替代解释或缺口 |
| --- | --- | --- |
| 需求真实且客户愿意付钱 | 终端使用、销量及价格、收入确认、应收和期后回款、渠道库存与退货 | 经销回款或预付货款只证明交易的一环，不能单独证明终端消化 |
| 品牌或技术能够保留溢价 | 可比产品/服务效果、价格与销量组合、分部毛利、研发及销售服务费用 | 提价、产品结构、渠道分利或成本周期也可能改变毛利；利润率本身不证明原因 |
| 企业与渠道共同创造价值 | 安装服务、渠道效率、库存承担、返利、促销、履约成本 | 直销可以转移原属渠道的利润，还要扣除新增零售与服务成本；终端价值须另证 |
| B2B设备改善客户经营 | 客户合格产出、售价、人工损耗、能耗维护及设备/改线投入 | 功能先进和客户回本分别核准；医疗机构收入增长与患者合理诊疗收益分别核准 |
| 收益能够支持下一轮经营 | 利润到经营现金桥、售后等必要义务、营运资金和维持资本开支 | 收入确认与客户收益兑现不同步；资金释放、金融本金及投资收益分别解释 |

关键表格和口径回PDF核准；证据四层沿用[分析指南第2节](analysis-guide.md#2-数据证据与计算纪律)。客户评价、访谈或渠道调查可补充视角，注明样本、日期、来源和局限，不能替代财报或代表全体客户。缺少终端、客户回报或履约数据时保留有限判断。

## 形成可复用结论

对重要业务写出一条有来源的解释：“谁为哪种结果付钱，企业凭什么交付并保留利润，利润如何收现；哪些证据支持，什么变化会使判断失效。”将尚未证实的动机、效果和渠道情况标为推断或缺口。

重要判断复用`finding`账本的事实/计算/推断及替代解释、缺口记录；引用使用其已支持的归档PDF或注册计算。外部材料按现有来源能力处理，未能绑定的证据在说明与缺口中保留。来源校验、数字核对、计算和索引同步交给现有CLI，见[案例与发现](case-workflow.md)、[计算工作流](calculation-workflow.md)和[证据检索](index-workflow.md)。

## 三家公司示例：学习追问方式

以下按2025年披露讨论业务机制，是研究假说与口径示例；以后分析须重查当期资料。它们不代替当前证据，也不构成“社会价值越大，利润越高”的排序。

| 业务 | 价值与责任关系 | 盈利解释及需核准的边界 |
| --- | --- | --- |
| 格力消费电器及空调相关业务 | 家庭/建筑使用者需要可靠、舒适和合理使用成本；经销商与工程客户还需要交付、周转和合作回报 | 产品、安装售后、品牌和制造效率共同支撑交易。检验终端体验、渠道库存与返利；消费电器分部与空调单品口径分别核准 |
| 茅台酒类业务 | 购买者、饮用者、受赠者和经销商可能不同；品质、真实性与信誉需要持续兑现 | 品牌共同认知可解释部分支付意愿，但消费动机须验证。直销影响价值分配；出货、渠道周转与终端需求分别判断，品牌不构成囤货收益承诺 |
| 美亚色选及检测设备 | 加工/回收企业购买更稳定的合格产出、分级能力和效率；消费者在下游受益 | 识别技术、现场工程与服务须转成可用设备；按客户新增可售产出和溢价、节省的人工损耗、维护与改线投入检验回报 |
| 美亚医疗设备 | 机构付款、医生使用、患者接受检查；机构经营回报与患者合理诊疗利益分别判断 | 核准影像及工作流价值、利用率与需求；医疗设备分部不全是CBCT。软件平台用户数量不自动证明经常性收入或续费能力 |

示例依据：[格力2025年报](https://disc.static.szse.cn/disc/disk03/finalpage/2026-04-29/f9937e4b-3994-4100-8200-7fd8a000ecfa.PDF)物理第11—12、24页；[茅台2025年报](https://static.cninfo.com.cn/finalpage/2026-04-17/1225114741.PDF)物理第8、10、21页；[美亚2025年报](https://static.cninfo.com.cn/finalpage/2026-03-31/1225055340.PDF)物理第10—14、18页。企业披露、计算与购买动机的分析推断仍按证据层次区分。
